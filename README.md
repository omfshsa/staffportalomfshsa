# OMFS HSA Staff Portal

Static GitHub Pages version with PWA/home-screen icon support.

## Files

- `index.html` — portal homepage
- `manifest.webmanifest` — Android/PWA install metadata
- `sw.js` — simple service worker for app-like install support
- `icons/` — iPhone and Android home-screen icons

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `omfs-hsa-staff-portal`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main`, folder `/root`, then **Save**.
6. Open the GitHub Pages URL after deployment finishes.

## Add to phone Home Screen

### iPhone
Open the GitHub Pages URL in Safari > Share > Add to Home Screen > Add.

### Android
Open the GitHub Pages URL in Chrome > menu > Add to Home screen or Install app.
